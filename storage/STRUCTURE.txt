IMPORT STRUCTURE:

External code:
    from storage.sqlite_store import SQLiteStore

↓

sqlite_store.py:
    from storage.sqlite_store_facade import SQLiteStore

↓

sqlite_store_facade.py (main facade):
    Creates instances of all 7 repositories
    Delegates method calls to appropriate repository

↓

Each repository:
    Inherits from BaseRepository
    Implements domain-specific methods
    Uses shared connection management
