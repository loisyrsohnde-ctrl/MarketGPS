  - Alert preview widget
  - Shows: unread count, critical count, recent alerts
  - Features: alert type icons, severity indicators

  - Opportunities display widget
  - Shows: Top 5 opportunities with scores
  - Features: opportunity type badges, confidence bars
  - Actions: add to watchlist buttons, asset links

/components/dashboard/NewsDigest.tsx
  - News widget with breaking and important sections
  - Shows: news titles, summaries, sources
  - Features: sentiment indicators, ticker tags
  - Navigation: external links to full articles

/components/dashboard/GamificationWidget.tsx
  - Gamification progress widget
  - Shows: level, points, weekly progress, objectives
  - Features: streak counter, progress bars
  - Displays: active objectives with rewards

/components/dashboard/index.ts
  - Barrel export for all dashboard components

/components/ui/loader.tsx
  - Loading spinner component
  - Variants: spinner, pulse, dots
  - Sizes: sm, md, lg

API ROUTES
----------
/app/api/portfolio/metrics/route.ts
  - GET endpoint for portfolio metrics
  - Returns mock data (to be replaced with real backend)

/app/api/alerts/route.ts
  - GET endpoint for alerts
  - Query param: limit (default 3)
  - Returns: unreadCount, criticalCount, recent alerts

/app/api/opportunities/route.ts
  - GET endpoint for opportunities
  - Query param: limit (default 5)
  - Returns: array of opportunities with assets

/app/api/news/digest/route.ts
  - GET endpoint for news digest
  - Query param: limit (default 5)
  - Returns: breaking news and important news

/app/api/gamification/status/route.ts
  - GET endpoint for gamification status
  - Returns: current level, points, objectives, streak

/app/api/watchlist/route.ts
  - POST endpoint for adding to watchlist
  - Body: { ticker, notes }
  - Returns: success status and confirmation
