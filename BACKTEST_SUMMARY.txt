================================================================================
PERFORMANCE METRICS PROVIDED
================================================================================

PERFORMANCE:
  - Total Return (%)
  - Annualized Return / CAGR (%)
  - Alpha vs Benchmark (percentage points)

RISK:
  - Annual Volatility (%)
  - Maximum Drawdown (%)
  - Sharpe Ratio (risk-adjusted return, >1 is good)
  - Sortino Ratio (downside risk only, usually >Sharpe)

WIN/LOSS:
  - Win Rate (%)
  - Winning Periods (count)
  - Losing Periods (count)
  - Best Period (%)
  - Worst Period (%)
  - Best Month (YYYY-MM)
  - Worst Month (YYYY-MM)

COMPARISON:
  - Benchmark Return (%)
  - Benchmark Volatility (%)
  - Benchmark Annualized Return (%)
  - Outperformance (Alpha)

TIME SERIES:
  - Equity Curve (daily values downsampled to ~250 points)
  - Drawdown Curve (peak-to-trough from peak)
  - Monthly Returns (period-by-period breakdown)

================================================================================
HOW TO USE
================================================================================

BACKEND DEVELOPERS:
  1. Import BacktestService: from backtest_service import BacktestService
  2. Create config: config = BacktestConfig(...)
  3. Run: result = service.run_backtest(config)
  4. Access metrics: result.total_return_pct, result.sharpe_ratio, etc.

FRONTEND DEVELOPERS:
  1. Use hook: const { result, runBacktest } = useBacktest()
  2. Configure: const config = { strategy_id, initial_capital, ... }
  3. Execute: await runBacktest(config)
  4. Display: <BacktestPanel compositions={...} />

API USERS:
  1. POST /api/backtest/run with composition and dates
  2. Receive complete metrics and time series data
  3. Visualize with equity curve and drawdown charts
