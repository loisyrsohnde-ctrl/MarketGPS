================================================================================
IMPLEMENTATION DETAILS
================================================================================

Bootstrap Module (core/bootstrap.py):
  - Function: bootstrap()
    * Loads environment variables once (via load_dotenv)
    * Sets up sys.path for proper package imports
    * Idempotent - safe to call multiple times
  
  - Function: ensure_bootstrap()
    * Returns True if this call triggered bootstrap
    * Returns False if already initialized
    * Used by config.py for safety

Pattern Used in All Modified Files:
  OLD:
    import sys
    from pathlib import Path
    sys.path.insert(0, str(Path(__file__).parent.parent))
    from dotenv import load_dotenv
    load_dotenv()
  
  NEW:
    from core.bootstrap import bootstrap
    bootstrap()
